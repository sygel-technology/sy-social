This module extends the functionality of mailing to show the document
followers in head of the mails. In the cc, only appear when:

1. The followers only count if are contacts or external users (Inner
   Followers will be discriminated)
2. The number of followers are more than 1.

Configuration
=============

To configure this module, you need to:

1. Go General settings/General Settings/Emails/Show Internal Users CC
   and set if want to show or not internal users in cc details.
2. Go Settings/Users & Company/Users and select any user in
   'Preferences' check or not the 'Show in CC' field if this user need
   to appear in the cc note.
